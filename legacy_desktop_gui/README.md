# Wersja archiwalna (desktop, CustomTkinter)

Ta wersja została zastąpiona aplikacją webową w katalogu nadrzędnym
(`server.py` + `templates/`), która działa zarówno na komputerze, jak i na
telefonie (ta sama baza danych, ten sam interfejs w przeglądarce).

Pliki w tym folderze nie są już utrzymywane i mogą nie działać
bez poprawek (baza danych i moduł `lookup` zmieniły trochę format od czasu,
gdy ta wersja była aktywna). Zostawione jako punkt odniesienia / archiwum.
